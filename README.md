# VoiceControlledLEDs
Create Voice Controlled LEDs using Gravity - DF2301Q Offline Voice Recognition Sensor, Arduino and WS2812B LED Strips.

## Prerequisites
1. Arduino Uno for <400 LEDs, Arduino Mega 2560 for >400 LEDs
2. LED two pin (Prefferably Blue)
3. Gravity - DF2301Q Offline Voice Recognition Sensor
4. LED Type: WS2812B
5. Power Supply - 5V & 10A

## Troubleshooting
If the Voice Recognition Sensor is unresponsive, unplug and replug the 5V wire from the Sensor and press the Reset button on the Arduino.
